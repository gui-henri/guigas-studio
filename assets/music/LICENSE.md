# Trilhas — assets/music/

Faixas de fundo licença-livre usadas como `soundtrack.track` no `script.json`.

## Como adicionar uma faixa

1. Baixe a faixa (Pixabay / incompetech / Free Music Archive) — MP3 ≤ 5 MB;
2. Renomeie para um identificador estável (`calm-loop.mp3`);
3. Registre AQUI: nome do arquivo → origem, autor, licença e exigência de crédito;
4. Commit — o server copia a faixa para o workspace no enqueue e ela viaja
   com checksum no manifest do job (S5-04).
